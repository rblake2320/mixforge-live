API Documentation

Base URL: your MixForge origin · Auth: Authorization: Bearer <token> from signup/login · All bodies JSON unless noted

Authentication

EndpointDescription
POST /api/auth/signup{email, password, name?} — password min 8 chars. Returns user + token (JWT, 14 days).
POST /api/auth/login{email, password} → user + token.
POST /api/auth/verify-email{token} from the verification email.
POST /api/auth/forgot-password{email} — always 200 (no account enumeration).
POST /api/auth/reset-password{token, password} — revokes all sessions issued before the reset.
GET /api/meCurrent user profile. Requires auth.

Catalog & community

EndpointDescription
GET /api/beatsBeat catalog.
GET /api/communityCommunity tracks.
GET /api/plansPlan catalog with pricing and features.

Recordings & projects

EndpointDescription
POST /api/recordingsmultipart/form-data with an audio file (≤100 MB, audio types only) + optional title, beatId, preset, durationSeconds.
GET /api/recordingsYour recordings when authenticated; anonymous callers see only ownerless rows.
GET /api/recordings/:id/audioStreams the audio. Owner-only for owned recordings.
POST /api/projects{title, mode?, recordingId?, beatId?, preset?, settings?}.
GET /api/projectsSame visibility rules as recordings.

Stem separation

EndpointDescription
POST /api/stems/jobsSource is one of: a track file upload (multipart, ≤150 MB), a saved recordingId, or a sourceUrl (YouTube, SoundCloud, or direct http(s) audio link). Demo mode returns a labeled preview; real mode requires StemSplit configuration.
GET /api/stems/jobs/:idJob status + stem outputs when complete. Owner-only for owned jobs.
POST /api/stems/webhookStemSplit provider webhook (signature-verified).

Billing

EndpointDescription
POST /api/billing/checkout{planId} — free activates directly; paid plans return a Stripe Checkout URL (auth required). Demo mode returns a labeled no-payment response.
POST /api/billing/webhookStripe webhook (signature-verified): checkout completion and subscription lifecycle.

Trust & safety

EndpointDescription
POST /api/reports{targetType: recording|community|user, targetId, reason, details?}.
POST /api/dmcaTakedown intake — see Rights & Licensing for required fields.
GET /api/legal/terms · GET /api/legal/dmcaMachine-readable policy summaries.
GET/POST /api/moderation/*Admin-only (x-admin-token header): review reports/takedowns, set recording moderation status.

Operations

EndpointDescription
GET /api/healthLiveness: store + log-storage checks, active backends, version.
GET /api/readinessLaunch checklist; 503 until production-ready.
GET /api/diagnosticsReadiness + logging detail. Admin-gated in production.
GET /api/logs/taxonomyStructured log taxonomy.

Errors & limits

Errors return {"error": "message"} with a meaningful status (400 validation, 401 auth, 403 ownership, 404 missing, 410 moderated, 429 rate-limited, 502/503 provider/config). Auth endpoints allow 40 requests / 15 min per IP; write endpoints (recordings, stems, checkout, reports, DMCA, contact) allow 30 / min per IP.
